# 走马岭的故事

故事纯属虚构，如有雷同就是雷同。

六月的一天 来到这个基地，其实人不多。 
1，在理发店，老板说前段时间这里发声过火灾。上报了2个，她说她知道的就死了4人，也有人说死了8人  

2，12点下楼，在小公园的亭子里，有人躺下了一动不动 有两三个警察把守现场。还以为挂了。吃完饭后看见来了救护车。听来的故事流程大概是这样的。这里不少人喜欢喝高了发酒疯，可能他们的大脑主板烧坏了30%。一个喜欢发酒疯惹事的人在过道碰瓷一个20多的小伙子，索要给买三瓶酒一盒烟，小伙子没有钱，说了一句"老子給你一根" ，然后发生了言语冲突也有肢体冲突，拉扯了一个多小时。最后一伙子回家拿了一把口径较窄的小刀，给了想讹他的那人5刀 据说是连续五刀。肯定有些动机的有两个人陪着一起喝酒应该也是有帮着欺负人的。不久那人就躺下了，小伙子主动去派出所自首了。被捅的那人进了icu 据说是脾受伤了。陪酒的两个人好像有参与，录完口供后又被公安再次带走。
